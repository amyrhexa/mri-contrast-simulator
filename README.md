# MRI Contrast Simulator

An interactive, physics-based MRI simulator for exploring how tissue relaxation properties and acquisition parameters influence MRI contrast.

## Features

- Simulates six pulse sequences: Spin Echo (SE), Fast Spin Echo (FSE), Gradient Echo (GRE), Echo Planar Imaging (EPI), Inversion Recovery (IR), and balanced SSFP (bSSFP).
- Interactive tissue phantom showing relative signal contrast.
- Visualises T1 recovery, T2 decay, and sequence timing.
- Adjustable acquisition parameters and predefined contrast presets.
- Includes model assumptions, tissue parameters, and scientific references.

## Scientific scope

This is an educational simulation, not a clinical imaging tool. Tissue parameters and signal calculations rely on documented assumptions and simplified physical models. Simulated images are not real MRI acquisitions.
